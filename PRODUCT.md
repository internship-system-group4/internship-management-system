# GJU Internship Management System

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Students seeking and completing internships, companies, company supervisors,
academic supervisors and university coordinators. The public Home page serves
visitors who need to understand the system and find available internship summaries.

## Product Purpose

Connect university study to internships through applications, placement confirmation,
training tasks, supervision and final review. Home introduces that journey and leads
visitors into the authenticated portal.

## Capabilities and Constraints

Existing ASP.NET Web Forms, Bootstrap 5, plain JavaScript, Firebase Database and
Authentication. Retain server controls, postbacks, protected routes and validation.
Only published public summaries may appear on Home. Private details and applications
require authentication. College/program/specialization content comes from project
Constants; university procedures must come from project documentation.

## Brand Commitments

German Jordanian University identity and original approved logo. The user authorized
a substantially larger and more distinctive Home redesign on 22 October 2026,
including freedom to change its prior composition. This authorization is specific
to Home and does not request redesigning the authenticated portals.

## Evidence on Hand

Seventeen university references in Assets/images/university, the existing procedural
Gate 1 and courtyard wheel, project workflow documentation and a Firebase-backed
public preview projection. No official explanation video or captions are available.
Hidden architectural dimensions and campus adjacency are unverified; the curated
scene must not be presented as a surveyed campus map.

## Accessibility & Inclusion

Semantic HTML content, keyboard navigation, visible focus, pause for ambient motion,
static reduced-motion presentation and photographic fallback if WebGL is unavailable.
Responsive desktop, tablet and mobile web. Current interface copy is English.
