# README showcase assets

`uims-journey.gif` is an original, illustrative workflow graphic, not an application screenshot or evidence of a completed end-to-end integration. All stages remain readable on the first frame. No student records or external imagery are included.

Regenerate with Python and Pillow:

```powershell
python docs/assets/generate-journey.py
```

The generator uses the repository's Noto Sans font (SIL OFL 1.1; see the existing font licenses). Its opaque navy canvas and high-contrast labels work in GitHub Light and Dark themes. Palette: navy `#10263B`, blue `#77B5F1`, teal `#57D1C1`, purple `#B9A1F5`, gold `#F3C66E`.

The GIF uses a gentle moving progress marker with no flashing. GitHub GIF embeds do not provide a reduced-motion media query or playback control; the first frame and the README's text/diagrams convey the same information without depending on playback.
